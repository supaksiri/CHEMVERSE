# CHEMVERSE 2.0 — Macro Lab Edition

ห้องปฏิบัติการเคมีเสมือน 3D ภาษาไทยที่ผู้เรียนสามารถ **หยิบ เท ผสม คนสาร และสังเกตปฏิกิริยาระดับมหภาค** ได้บน GitHub Pages

## สิ่งที่เพิ่มจาก Version 1

- ขวดสาร A/B เป็นวัตถุ 3D ที่แตะเพื่อเริ่มเทได้
- ลำดับปฏิบัติจริง: เตรียม → เท A → เท B → คนสาร → สังเกต
- แอนิเมชันยกขวด เอียงขวด สายของเหลว และระดับของเหลวที่เปลี่ยนตามปริมาตร
- ของเหลวในขวดต้นทางลดลงขณะเท
- การผสมสีและผิวของเหลวกระเพื่อม
- ตะกอนค่อย ๆ เกิดและตกลงก้นภาชนะ
- ฟองแก๊สเกิดจากก้นสารละลายและลอยขึ้นสู่ผิว
- ของแข็งโลหะเกิดและสะสมในปฏิกิริยารีดอกซ์
- สีของสารเชิงซ้อนกระจายในปฏิกิริยาสมดุล
- ความร้อนแสดงบน hot plate และค่าจากเทอร์มอมิเตอร์
- Macro Evidence แยกหลักฐานด้านสี ตะกอน แก๊ส และอุณหภูมิ
- โหมดสาธิตอัตโนมัติสำหรับครู
- Performance, Balanced และ Cinematic Mode

## ระบบเดิมที่ยังคงอยู่

- ห้องทดลอง 6 โซน
- สารตั้งต้น 16 ชนิดและปฏิกิริยาหลัก 9 แบบ
- ภารกิจ 6 ด่าน ระบบ XP และระดับผู้เรียน
- Particle Vision และกราฟแบบเรียลไทม์
- ATOM ผู้ช่วยแบบคำถามนำ 3 ระดับ
- Pressure Critical และ Incident Analysis
- Lab Notebook พร้อมพิมพ์หรือบันทึก PDF
- บันทึกความก้าวหน้าในอุปกรณ์
- Responsive และ PWA

## GitHub Pages

โปรเจกต์มี `.github/workflows/deploy.yml` แล้ว ให้อัปโหลดโฟลเดอร์ `.github` ไปด้วย จากนั้นเลือก **Settings → Pages → Source → GitHub Actions**

> หากอัปโหลดผ่านหน้าเว็บ GitHub แล้วไม่เห็น `.github` ให้สร้างไฟล์ `.github/workflows/deploy.yml` ผ่านเมนู Add file → Create new file
